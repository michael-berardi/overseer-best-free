# Security Policy

## Scope

`overseer-free-best` makes exactly one kind of network request: a read-only fetch of the public OpenRouter model catalog (`https://openrouter.ai/api/v1/models`). It stores nothing, executes nothing from responses, and never asks for or handles API keys.

## Reporting a vulnerability

Please open a private security advisory via GitHub (*Security → Report a vulnerability*) rather than a public issue. Reports receive a response within 7 days.
